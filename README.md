## Qué puedo hacer por ti

- **Webs para empresas:** webs corporativas con diseño propio, textos pensados para vender, una base SEO sólida y el objetivo de 100/100 en PageSpeed.
- **Aplicaciones y plataformas web a medida:** áreas de cliente, paneles de gestión, reservas, intranets y herramientas internas con PHP, Laravel y MySQL.
- **Tiendas online:** con WooCommerce o a medida, del catálogo a la conexión con tu ERP o tu CRM.
- **WordPress a medida:** temas, bloques y plugins propios, fáciles de gestionar.
- **Integraciones y automatizaciones:** conexión entre plataformas, APIs y procesos que ahorran trabajo manual.
- **Mantenimiento y evolución:** actualizaciones, incidencias y mejoras, con cada petición a la vista en tu portal de cliente.
